# ⚡ BARQ-MV — موزیک‌ویدئوی «تعطیل (برقِ من)» · فریم‌به‌فریم
### ریپوزیتوریِ تولید: مینیاتورِ GTA — شخصیت‌های ما، فریم به فریم، چسبانده‌شده به جیف
> امضا: K1RT!0NARi · ابعادِ روایت: طومارِ نقاشیِ صفوی از دیدِ بالا، راست به چپ · ۱۰۵ BPM (بیت = ۰٫۵۷۱s)

**یک خط:** این ریپو کارخانهٔ ساختِ موزیک‌ویدئوی «تعطیل» با روشِ زنجیرهٔ فریم است — با مدلِ تصویر (نه مدلِ ویدئو): هر سکانس یک قابِ لنگر، بعد فریم‌های دلتا با قفلِ قاب، بعد هم‌قاب‌سازی و مونتاژ به جیف.

## 🔁 گردشِ کار (برای هر سکانس)

1. **بخوان:** `docs/style-bible.md` (قوانین) + ردیفِ سکانس در `docs/production-plan.md` + گام‌ها در `docs/timing-map.md`
2. **لنگر:** پرومپتِ آماده از `prompts/anchors.md` + بلوکِ سبک + مراجعِ شخصیت از `refs/`
3. **فریم‌ها:** هر فریم با مرجعِ لنگر + دلتا + **جملهٔ قفلِ قاب** (حلقه‌های تنگ: همیشه از لنگر، نه زنجیره!)
4. **هم‌قاب:** `python3 tools/align_frames.py frames/NN-slug F1.jpg F2r.jpg … --out loop.gif` → بستنِ حلقه باید ≤ ۱۲ شود
5. **مونتاژ:** spec در `shots/NN-slug.json` → `python3 tools/build_shot.py shots/NN-slug.json`
6. **لاگ + کامیت:** لاگ کامل (قولِ وات‌به‌وات) در `logs/` → آپلود

نمونهٔ کاملِ هر شش مرحله: `frames/00-pilot-candle/` + `logs/scene-pilot-candle.md`

## ⚖️ قوانینِ این ریپو (خلاصه — کامل در مسترِ سند)

1. **هیچ جیفی بدونِ `align_frames.py`** — قاب در همهٔ فریم‌ها یک‌جا و یک‌اندازه
2. **هیچ فریمی بدونِ لاگ** — پرومپتِ وات‌به‌وات؛ لاگ ناقص = سکانسِ تحویل‌نشده
3. فریم‌های ردشده **پاک نمی‌شوند** — `-REJECTED` می‌خورند و می‌مانند
4. سبک و پالت و توکن‌های شخصیت قفل‌اند (docs/style-bible.md + master-prompt.md §۱٫۳)
5. ریتم: حلقهٔ ۷ فریمی @۸۰ms = یک بیتِ ۱۰۵
